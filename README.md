### 👨‍💻 About Me

I'm a software engineer and researcher based in **Bengaluru, India**, holding a **Bachelor of Computer Applications (BCA)** from **REVA University**. Currently, I engineer spatial web platforms at **[The Realty Engineers](https://www.therealtyengineers.com/)**, replacing static real estate directories with interactive, vector-mapped cartographic systems.

My broader technical focus bridges **Computer Vision & Deep Learning Forensics** with **Geospatial Engineering & Modern Full-Stack Systems**.

- 💼 **Current Role:** Software Engineer at **The Realty Engineers** — developing interactive GIS maps, layout boundary overlays, and real-time buyer dashboards.
- 🎓 **Education:** BCA, REVA University.
- 🔭 **Core Specialization:** Deepfake Forensics, Multimodal Signal Processing, Geospatial/Cartographic Platforms, and Local AI/RAG Pipelines.
- 💬 **Ask me about:** Python, PyTorch, OpenCV, Mapbox GL / Leaflet, GeoJSON, FastAPI, React, Vector DBs, and Modern UI/UX.
- ⚡ **Philosophy:** Engineering systems with explainability, spatial accuracy, and real-world performance.
